New Things I Learned

While creating this website, I learned some new HTML and CSS techniques and understood how they can be used in a website.

1. HTML Optgroup

I learned how to use the optgroup element to organize related options inside a dropdown list. I used it in the registration form to separate clubs from workshops and events.

2. CSS Pseudo-elements

I learned how to use the ::before pseudo-element to add extra content using CSS without adding another HTML element. I used it on the activity cards to display a small club label.

3. CSS Object-fit

I learned how to use the object-fit property to fit images properly inside a fixed area. I used object-fit: cover for different images so that they look neat without getting stretched.
